🛠 Flowchart Editor Instructions

  • 👉 Click on empty space to add a node.
  • ✍️ Double-click a node to edit its text.
  • 🖱️ Drag nodes to reposition.
  • ⇧ Shift + Drag a node onto another to connect them with an arrow.

Each node is styled with a pastel color and can be moved freely. Try creating a simple workflow!

Tip: This app runs fully in your browser — no internet connection needed after loading.
